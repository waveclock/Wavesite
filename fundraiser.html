How it works

Getting started

Step 1

Request a code

Email hello@waveclock.net with your team or organization's name. We'll set you up with your own discount code.

Step 2

Share it

Pass your code along to supporters — text, email, a flyer, whatever works. They enter it at checkout on the order page.

Step 3

Get paid

We tally up sales made with your code and send your team $10 for each one.

Heads up: this program is brand new, so it's run by hand for now — codes and payouts are set up individually rather than through an automated dashboard. If you're organizing a fundraiser for a sports team, school club, or similar group, reach out and we'll get you going.
